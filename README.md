## 🔧 Supported Conversions

### MQL4 → MQL5
- Function rewrites: `start()` → `OnTick()`, `init()` → `OnInit()`
- Order constants: `OP_BUY` → `ORDER_TYPE_BUY`
- Indicator migration: `iMA()` → Handle-based approach
- Market info: `MarketInfo()` → `SymbolInfoDouble()`
- Variables: `Bid/Ask` → `SymbolInfoDouble(_Symbol, SYMBOL_BID/ASK)`

### MQL5 → MQL4
- Reverse conversions with compatibility warnings
- Netting vs hedging mode warnings
